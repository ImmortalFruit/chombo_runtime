# 手牌図の生成

最初に Agent のワークスペース依存ランタイムを読み込み、そこで提供された Python 実行ファイルを使う。システムの `python3` は使用しない。提供された Python でこの Skill の `scripts/generate_hand.py` に牌列を渡す。出力先やファイル名は指定しない。

```bash
<workspace-python> skills/render-hand/scripts/generate_hand.py '111s067pf(22-22m)f(x55xz)66z'
```

`<workspace-python>` は依存ランタイムの読み込み結果に含まれる Python 実行ファイルの絶対パスに置き換える。このランタイムには Pillow が含まれる。依存ランタイムを読み込めない場合は実行を中止し、その旨を簡潔に伝える。パッケージの追加インストールや外部リソースの取得は行わない。

## 入力

- 数牌は数字列の直後に `m`（萬子）、`p`（筒子）、`s`（索子）を置く。数字は `1`〜`9`、赤5牌は `0` で指定する。
- 同じ系統の牌は `123m` のようにまとめても、`1m2m3m` のように各牌へ系統記号を付けてもよい。まとめ表記、完全表記、および両者の混在を同じ牌列として扱う。
- 字牌は数字列の直後に `z` を置く。`1`〜`7` は東・南・西・北・白・發・中の順とする。漢字の `東南西北白發中` も対応する字牌として受け付ける。
- 赤5牌は `0m`・`0p`・`0s` のほか、同じ牌を表す入力別名 `r5m`・`r5p`・`r5s` も受け付ける。
- 複数の数字列と種別を連結できる。半角空白、全角空白、タブ、改行などの空白文字はすべて無視される。
- 伏牌は `x`、横牌は対象牌の直前に `-` を置く。
- 副露など、手牌から離して表示する配置グループは `f(...)` で囲み、複数グループを指定できる。グループがチー・ポン・槓として成立するかは判定しない。
- 重ね表示は `f(...)` 内の横牌直後に `k` を置き、続く実牌をその横牌の上へ重ねる。典型的には加槓の表示に使用するが、同一牌か、加槓として成立するかは判定しない。例: `f(22-2k2m)`。
- 式末尾の牌種を、牌種を省略した手牌・副露へ適用できる。例: `22f(234)f(x66x)s`。
- ランダム選出は `[mpsz]N[r]` とし、`N` は1〜14、`r` は赤5牌を含む指定とする。例: `m14r`、`z7`、`14`。
- 明示された牌列は入力順を保持し、自動では理牌しない。
- ランダム作成または自動作成では、個別に理牌しない規定がない限り、`m`・`p`・`s`・`z` の順、各系統内は数字順で理牌する。14枚を作成した場合は、最初の13枚を理牌し、最後の1枚を自摸牌として末尾に残す。
- 麻雀の物理的な牌構成は検証しない。同一牌5枚以上、同一系統の赤牌複数枚、14枚を超える牌列、不成立な配置グループも、構文上描画できれば受け付ける。
- 過大な画像生成を防ぐ描画資源上限として、表示牌は1〜30枚、`f(...)` の配置グループは最大8組とする。この上限は麻雀ルール上の妥当性を意味しない。
- 例: `123m405p17z`、`1m2m3m r5p 東中`、`11122s333p456m77z 2s`

`help` を渡すと対応記法を表示する。許可されていない文字列、壊れた構文、空の配置グループ、描画資源上限を超える指定、または画像化できない指定が入力された場合は、警告と理由を表示して終了する。描画対象が成立例・不成立例・中断例のどれであるかを判断せず、指定された牌配置と表示状態を描画する。牌の物理的枚数、チー・ポン・槓、門前、和了などの妥当性判定は将来のEngineの責務とする。

Skillの入力規定は `concepts/compact-tile-notation.json` の `QUALIFIED` Conceptを牌記法の正本として参照する。Skill固有の `x`、`-`、`f(...)`、`k`、ランダム指定、空白処理、理牌、描画資源上限は表示入力契約として本書で定める。Concept契約テストと表示回帰テストにより、同値な牌記法が同じ牌画像になることを保証する。

## 出力

- PNGは `<project-root>/outputs/` に保存する。ディレクトリがなければ生成時に作成される。
- ファイル名はローカル時刻・マイクロ秒・UTCオフセットを含む。例: `20260808T153045.123456+0900.png`。
- 白背景に牌間を2px空けて並べる。手牌と配置グループ、配置グループ同士は40px空け、換算14枚の場合は手牌の最終牌を自摸牌として離す。
- 合成後、画像全体を元寸法の40%へ縮小する。
- 生成に成功したら、生成されたPNGをユーザーに表示する。
- 入力を解析できない、または生成に失敗した場合は、原因と正しい入力形式を簡潔に説明する。

## 画像リソース

牌画像は `assets/mahjong-tiles/` にある。伏牌には `facedown.png` を使用し、横牌は通常牌または伏牌を回転して描画する。

返却された資格・来歴・依存を確認し、未資格・欠落・破損時は説明を停止する。
